03 · RECEITA MINERAL

CFEM: pagamentos e repasses

A arrecadação registra os pagamentos pela exploração mineral no território. Os repasses são os valores que entraram para as prefeituras, inclusive quando o município recebe por ser afetado pela mineração.

05 · TRANSPARÊNCIA

Como ler este diagnóstico

Território

O recorte usa os vínculos de ProcessoMunicipio. A área informada na ficha é a área total cadastrada do processo. Para medir a parte dentro de um município, é necessário cruzar as poligonais com o limite municipal.

Titulares, fases e substâncias

O painel apresenta o recorte cadastral do arquivo, com titulares/requerentes e substâncias sem encerramento registrado. Use a ficha da ANM para confirmar a situação de cada título.

Dados financeiros

Valores nominais. Um travessão indica ausência de registro na fonte para o recorte.
